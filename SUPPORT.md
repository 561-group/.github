# Help, support and contact

For questions, support, services, and business inquiries use [561 Group contact](https://561.group/contact/). For ordinary software defects or feature suggestions, open an issue in the **affected repository** (not automatically in this corporate `.github` repository).

For security vulnerabilities, use the affected repository's **Security → Report a vulnerability** option when available. Otherwise contact the Group without publishing exploit details in an issue.

For business-specific customer and seller flows follow that service's published intake path. A GitHub issue is not a confidential support ticket or an accepted work order.
