# Security reporting

**Do not open a public issue for a security vulnerability.** On the *affected repository*, choose **Security → Report a vulnerability** if private vulnerability reporting is enabled. If the option is unavailable, use [561 Group contact](https://561.group/contact/) and request a private disclosure channel before sending sensitive details.

Do not post passwords, tokens, personal information, exploit material, or private raw logs in issues or pull requests. If credentials are already exposed, revoke or rotate them using the credential owner's authorized process.

Secret scanning, push protection, private reporting, and repository rules are configuration-dependent: this document alone does not establish that they are enabled. Their actual status must be verified in each repository's settings.
