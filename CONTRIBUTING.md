# Contributing

This is the default contributing guide for 561 Group repositories. A repository's own CONTRIBUTING file, templates
and LICENSE take precedence over it.

- Search existing issues and pull requests before opening a new one.
- Report bugs and request features in the repository they concern, using its issue forms.
- Keep a pull request to one change. Say what it changes, why, and how you checked it.
- Follow the repository's own build, test and style instructions.
- Never put passwords, tokens, private logs or personal data in an issue or pull request.
- Report security vulnerabilities privately; see [SECURITY.md](SECURITY.md).

Contributions to a repository are made under that repository's LICENSE.

For anything that is not a bug, feature or change to a repository, use https://561.group/contact/.
